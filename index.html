Where should visuals come from?

Intro clips are capped at 6 seconds; main-story clips are capped at 13 seconds each. The first scene starts as the intro, and you can change any scene in the timeline.

Choose a visual source, upload narration, then match the scenes to your clips or search online. Speech recognition runs on this device.
Visual sources and API keys

Keys stay only in this open tab and are never saved or included in project files. Requests go directly from your browser to each provider, so keys are visible to browser tools; for a public website, use a secure server proxy instead. Wikimedia Commons photos remain available without a key.
